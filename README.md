# PDP Clone — Portfólio

Clone de interface de uma página de produto (PDP) de marketplace, feito para currículo e estudo de front-end. Sem vínculo com o TikTok ou a TikTok Shop; o botão de compra não executa nenhuma transação.

**Demo:** https://pdp-clone-portfolio.vercel.app

## Stack
- React + Vite
- lucide-react (ícones)
- CSS puro

## Funcionalidades
- Galeria com miniaturas roláveis e troca de imagem no hover
- Timer de oferta em contagem regressiva
- Seletor de quantidade, seções recolhíveis e "Ver mais" na descrição
- Coluna de compra fixa (sticky) durante a rolagem
- Carrossel de produtos relacionados com setas que aparecem/somem nas bordas

## Rodando localmente
```bash
npm install
npm run dev
```
